# Button Sender

Button Sender by BITBEAST PRIVATE LIMITED.

## Installation

### macOS

**Pick the download matching your CPU chip:**

- **Apple Silicon (M1/M2/M3):** files containing `arm64` (e.g. `Button-Sender-1.0.0-arm64.dmg` or `Button-Sender-1.0.0-arm64-mac.zip`)
- **Intel:** files **without** `arm64` (e.g. `Button-Sender-1.0.0.dmg` or `Button-Sender-1.0.0-mac.zip`)

**Install and open (step-by-step):**

1. Download the correct file for your chip from the [Releases page](https://github.com/digi-bulk-marketing/button-sender-mac/releases/latest).
2. Open the `.dmg` (or unzip the `.zip`) and drag **Button Sender** into `/Applications`.
3. If macOS blocks the app, open Terminal and run:

   ```bash
   sudo xattr -rd com.apple.quarantine "/Applications/Button Sender.app"
   ```

4. Launch **Button Sender** from Applications.

> If macOS shows a quarantine warning ("app is damaged" / "cannot be opened"), run the Terminal command above to unblock it, then launch again.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/button-sender-mac/releases/latest) and reinstall.
